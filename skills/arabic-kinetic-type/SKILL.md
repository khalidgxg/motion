# الطباعة العربية المتحركة

حافظ على تشكيل العربية واتصال الحروف أثناء بناء حركة مقروءة.

## طريقة الاستخدام
اقرأ المدخلات والقيود من طلب المستخدم وملفات المشروع. استنتج الخيارات القابلة للعكس، واسأل فقط عمّا يمنع التنفيذ. لا تفترض توفر محرر أو renderer أو حساب مدفوع. نفّذ داخل المشروع عندما تكون الأدوات متاحة، ثم افحص الناتج. لا تدّع تنفيذ رندر أو مشاهدة مرجع لم تنفذه أو تشاهده.

## خطوات العمل

1. ثبّت النص واعتمد خطًا مرخصًا يدعم العربية. انتظر تحميل الخط قبل القياس أو الرندر، ولا تعتمد على fallback غير معروف.
2. اضبط direction: rtl وlang="ar" للنص العربي، واعزل الأرقام والروابط والإنجليزية بـ bdi أو مقاطع ذات اتجاه صريح. اختبر العملة والنسب والأقواس.
3. حرّك الكلمات أو السطور عبر clip أو transform. لا تقسّم العربية إلى حروف DOM منفصلة؛ حتى تقسيم graphemes لا يضمن بقاء اتصال الخط.
4. في التأثيرات الحرفية المعقدة استخدم outlines مشكّلة من أداة موثوقة بعد تثبيت النص، واحتفظ بنسخة نصية قابلة للتعديل ووصف متاح للويب.
5. راجع التشكيل والنقاط واللام ألف والقص عند أعلى وأسفل السطر. لا تعكس ترتيب النص يدويًا. اختبر العرض النهائي والخلفيات المتغيرة.

## المخرجات

مكون طباعة عربية، عينات نصية مختلطة الاتجاه، لقطات بداية ووسط ونهاية.

## بوابة الجودة

حروف متصلة؛ نقاط وتشكيل سليمان؛ ترتيب صحيح للأرقام؛ لا قص؛ زمن قراءة كافٍ.

## مثال طلب

> حرّك «أفكارك تتحرك» كسطر عربي متصل مع إبراز كلمة تتحرك وقيمة 25%.
