# تسليم SVG وLottie

سلّم رسومًا متجهة ضمن حدود المشغّل المستهدف.

## طريقة الاستخدام
اقرأ المدخلات والقيود من طلب المستخدم وملفات المشروع. استنتج الخيارات القابلة للعكس، واسأل فقط عمّا يمنع التنفيذ. لا تفترض توفر محرر أو renderer أو حساب مدفوع. نفّذ داخل المشروع عندما تكون الأدوات متاحة، ثم افحص الناتج. لا تدّع تنفيذ رندر أو مشاهدة مرجع لم تنفذه أو تشاهده.

## خطوات العمل

1. حدّد player والمنصة والإصدار والميزانية ونمط loop/autoplay. لا تفترض تكافؤ دعم web وiOS وAndroid.
2. قلّل عدد المسارات والنقاط والطبقات والماسكات. لا تصدّر تأثيرات raster معقدة على افتراض دعمها.
3. راجع ميزات المشروع مقابل دعم player. إن تعذر تأثير فحوّله إلى شكل مدعوم أو اختر فيديو؛ لا تسقطه بصمت.
4. اختبر بداية ووسط ونهاية وloop في player الحقيقي. بالنسبة للويب دمر instance عند unmount وتعامل مع data_failed.
5. سلّم JSON والأصول التابعة وposter ووصفًا متاحًا. راجع الخطوط وحقوقها وخيار تحويل النص إلى outlines مقابل حجم الملف وإمكانية التعديل.

## المخرجات

JSON وأصوله أو SVG، ملف معاينة، poster، تقرير دعم المنصات.

## بوابة الجودة

لا صور مفقودة؛ لا أخطاء masks؛ loop سلس؛ الحجم ضمن الميزانية؛ النص صحيح.
