# الرندر وفحص الجودة

أثبت جودة التسليم عبر الصورة والصوت والبيانات الفعلية.

## طريقة الاستخدام
اقرأ المدخلات والقيود من طلب المستخدم وملفات المشروع. استنتج الخيارات القابلة للعكس، واسأل فقط عمّا يمنع التنفيذ. لا تفترض توفر محرر أو renderer أو حساب مدفوع. نفّذ داخل المشروع عندما تكون الأدوات متاحة، ثم افحص الناتج. لا تدّع تنفيذ رندر أو مشاهدة مرجع لم تنفذه أو تشاهده.

## خطوات العمل

1. عرّف codec/container والدقة وfps والمدة ومساحة اللون والصوت وalpha وفق التسليم، ولا تفترض أن MP4 المعتاد يدعم الشفافية.
2. افحص sample render قبل النهائي. راجع أول وآخر إطار وكل transition والنص العربي وحواف الأقنعة والظلال.
3. استخدم ffprobe لفحص streams والدقة والمدة وfps والصوت. راجع frame count عند الحاجة مع مراعاة variable frame rate.
4. شاهد الملف المصدر نفسه، ثم النسخة المضغوطة. افصل ما تم فحصه بصريًا عما استُنتج من metadata.
5. دوّن blockers بصيغة: frame أو timecode، المشكلة، السبب المحتمل، التصحيح، نتيجة إعادة الفحص. لا تساوِ نجاح أمر التصدير بصحة المحتوى.

## المخرجات

فيديو التسليم، master إن طُلب، صور مختارة، qa-report.md بأدلة واضحة.

## بوابة الجودة

لا قص أو خط بديل؛ لا شاشة سوداء عرضية؛ الصوت متزامن؛ الاسم والدقة والنسبة صحيحان.
